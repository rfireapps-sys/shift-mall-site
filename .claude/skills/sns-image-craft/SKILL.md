# SNS画像の作り方と考え方

目的は、自動生成っぽいと見られない、細部まで詰めた画像を出すこと。好みではなく、**根拠と測定**で決める。手を動かす前に考える順番を守る。

## 1. 考える(作る前)

1. **誰に・何を・なぜ・いつどこで**を先に決める。相手はこの画像にまだ関心がないと考え、流れていくフィードの中で一瞬で何を感じてほしいかを一文で言う。
2. **主役を1つに絞る**(スポットライト)。主役以外は役割が言えるものだけ残す。役割が言えない要素(飾りのボタン、バッジ、シール、ロゴもどき)は入れない。
3. **言葉で先に考える**。見た目を考える前に、伝えたい印象のキーワードを5〜6個に絞り、それを満たすかをあとのチェック基準にする。
4. **色・形・書体を「人物」に例える**。この書体はどんな人が話しているか。その人物が、コピーを言う人と合うかを確かめる。
5. **既存の見た目と統一する**。同じブランドの他の面(サイト、アプリ、他のSNS、ロゴ)を見て、色・書体・傾き・角の形をそろえる。統一を壊す要素は足さない。
6. **根拠の資料を読む**。ブランドのルール、デザイン書の読書メモ、CLAUDE.md、コピーの禁止語。根拠は、「どの資料のどの項目」と名指しで言えるようにする。
7. **見られる場面**を調べる。表示サイズ、トリミング、上に重なる要素。フィードでは幅500px前後に縮むことが多く、この縮尺で読める大きさにする。サイズや切り取り比率は変わりやすいので、最新の情報を毎回確認する。

## 2. 設計の原則

**レイアウトの4原則**
- コントラスト: 要素(書体・色・大きさ・線の太さ)を似せず、違いをはっきりさせる。中途半端な違いは「衝突」になる。つけるなら大胆に。
- 反復: 色・形・余白・角の形のルールを全体で繰り返す。
- 整列: 全要素を意図して置く。中央揃えと左揃えを混ぜない。
- 近接: 関連するものは近く、関連しないものは離す。
- 空白を怖がらない。極端な大小や左右非対称も恐れない。

**色**
- 配分は、ベース約7割・同系約2割・正反対約1割を目安にする。色と色の間に細い無彩色を挟むと引き立つ。
- 同じ色でも、面積が大きいほど明るく見える(面積効果)。面積に合わせて明度を調整する。
- グラデーションやぴったりな混色は、自動生成っぽく見える。ハードエッジでフラットな配色にする。
- 影や縁は、背景との明暗差が小さいと、影ではなく汚れに見える。背景を変えたときは見え方を確かめ直す。
- 文字と背景のコントラスト比は計算で確かめる(本文は4.5:1以上、大きい見出しは3:1以上)。

**書体**
- 印象の目安: 明朝体=落ち着いた信頼感、ゴシック体=力強くモダンで読みやすい、丸ゴシック=柔らかくて子供っぽい、装飾書体=見出し向け。
- 太字が足りないとき、輪郭を足して太らせない(角が丸くなり、カウンターがつぶれる)。元から太いウェイトを持つ書体を選ぶ。
- 極太の装飾書体は、細い線がつぶれて別の字に見えることがある。選ぶ前に、実寸と縮小の両方で試す。
- 1行は長すぎない(目安: 40〜50文字が上限)。短いとテンポがよく軽快、長いと重厚になる。改行は文節や意味の切れ目でする。
- 書体の案を出すときは、3案を並べ、この1点以外はそろえる。それぞれの根拠と、既存の書体からずれることを言う。

**文字の位置**
- 数値上の上下中央と、目で見た中央はずれる。数値で中央に置くと、気持ち下に見える。箱の中の文字は、少し上げて目で確かめる。

## 3. 作る
- コードで描くとき: 設計を整数の単位で置き、高い倍率で描いてから縮小する。余白は固定値を決め、すべての要素の外枠をそろえる。
- 文字の位置は、フォントの枠ではなく、**字のインクの境界**で測ってそろえる。
- 日本語は、プロポーショナル詰め(palt)とカーニングを有効にし、文字列ごと描く。これらの機能を持たない書体は、fontToolsで確認し、かなが開く場合は手で詰める。
- 他の面とそろえる値(傾き、間隔など)は、参考画像から測る。目分量で決めない。
- 小さい文字(名前や日付)は、縮小表示で読める大きさにする。幅の目安、1600px幅で約48px以上。
- 主役とその他の間に、はっきりした大小の差をつける。同格の要素どうし、大きさを似せると中途半端になる。

## 4. 測る(作るときとレビューで必ずやる)
見た目だけで「そろっている」と判断しない。出力した画像を読み込んで測る。
- **箱や帯の中の文字の余白**: 文字(インク)と箱の間を、列ごと・行ごとに測って平均する。箱が傾いていると、一点だけでは値がぶれる。傾きの影響を受けにくいよう、文字の左端の数列を使う。
- **目標値**: 四辺をほぼ同じにする。ただし、上は下より少し狭く(目安: 10〜15%)し、目で見て中央に見えるようにする。数値で同じにしただけでは、文字が下に見える。
- **要素間の間隔**: 左右・上下の間隔を、実際のピクセルで測る。
- **左端と右端**: 画像全体の資産の左端・右端を、背景色との差で測る。
- **測れないことは、「測っていない」「目視」と明記する**。傾けた箱の右側の余白は、字形の違いで差が出る。測った場所と、測らなかった場所を分けて伝える。

## 5. 厳しい自己レビュー(必ず入れる)
プロのデザイナーとして、重い順に挙げ、測れるものは測る。
1. 目的とのちがい(主役が主役に見えるか、キーワードを満たすか)
2. 他の面との統一(色、書体、傾き、角の形)
3. 書体の人物像と、内容の調子が合っているか
4. 縮小したときの読みやすさ(小さい文字の大きさ、細い線のつぶれ)。実際に縮小して見る
5. 余白と間隔(第4章の測定値で判断する)
6. 階層(大・中・小の差が明確か、中途半端な差がないか)
7. 色のコントラスト比
8. 原則との照合(4原則、色の配分、文字の中央の視覚補正)

## 6. 直して出す
- 直す案は自分で決め、根拠を添えて出す。案を並べるのは、書体のように好みが割れる1点だけにする。
- ファイルとして送る。表示されないと言われたら、添付で送り直し、置き場所を説明する。
- 日本語の文章は、推敲してから出す。
- 「出して恥ずかしくないか」と聞かれたら、直した点と、残っている甘い点の両方を正直に言う。ほめすぎない。
